### SLIDE 4: PROBLEMA ATUAL
**Título:** Desafios Identificados

**4 Problemas Principais:**
1. **Limitações dos Modelos Tradicionais**
   - Modelos estáticos que não aprendem
   - Necessidade de grandes volumes de dados anotados

2. **Problemas de Anotação**
   - Processo manual trabalhoso
   - Alto custo de tempo e recursos

3. **Falta de Inteligência Contextual**
   - Sistemas não "entendem" conceitos
   - Dificuldade em generalizar

4. **Ausência de Auto-Melhoria**
   - Sistemas não evoluem com o tempo
   - Sem mecanismo de retroalimentação

**Processo:**
1. Análise de mapas de calor
2. Conversão em bounding boxes
3. Geração de arquivos YOLO
4. Validação automática

**Imagem:** Mapas de calor Grad-CAM

---

### SLIDE 14: ESTRATÉGIAS - VALIDAÇÃO HÍBRIDA
**Título:** Validação Híbrida

**Estratégia:** Múltiplas fontes de validação

**Componentes:**
- APIs de Visão (Gemini, GPT-4V)
- Grad-CAM (força do mapa de calor)

**Decisões:**
- AUTO-APROVAÇÃO: API confirma + Grad-CAM forte
- AUTO-REJEIÇÃO: API rejeita
- REVISÃO HUMANA: API confirma mas Grad-CAM fraco

**Imagem:** Fluxo de validação
